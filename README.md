# danbooru-tag-categories-ja

Danbooruタグの日本語名とカテゴリ分類をまとめたCSVデータです。

## 目的

英語のDanbooruタグを、日本語UI・検索・タグ補完・画像管理・プロンプト補助などで扱いやすくするための辞書です。

## ファイル

- `index.csv`: タグ辞書本体
- `data/appearance_tag_additions.csv`: 2026年9月4日にDanbooru APIで確認し、翻訳と分類をレビューした追加タグの台帳
- `data/manual_audit_corrections.csv`: `index.csv` 全件の目視監査で確定した修正台帳。修正前後の訳・カテゴリと理由を記録
- `scripts/tag_classification.py`: 髪・目・肌と表情を分ける分類ルール
- `scripts/refine_index.py`: 既存タグの再分類、追加タグの連番付与、目視修正台帳の適用を行う再生成スクリプト
- `tests/`: 分類ルールとCSV更新処理のテスト

## 列

- `index`: 通し番号
- `tag`: Danbooruタグ
- `db_category_filled`: 英語カテゴリ
- `tag_jp`: 日本語名
- `category_jp`: 日本語カテゴリ

## 分類方針

`category_jp` は、画像生成用にタグを選別しやすくするため、外見系の混合カテゴリを整理しています。

- `髪`: 頭髪の色、長さ、前髪、結び方、編み方、髪型、質感
- `目`: 目の色、虹彩、瞳孔、強膜、まつげ、眉などの目元の外見
- `肌`: 肌の色、質感、そばかす、日焼け、ほくろ
- `表情・感情`: `wink`、`one_eye_closed`、`closed_eyes`、目を細める・そらすなど、表情や目の動き

髪飾り・眼鏡・化粧は `アクセサリー` または `化粧・装飾`、髪や目を扱う動作は `ポーズ・動作`、目や身体部位の遮蔽・汚れ・生理状態は `状態・様子` または `状態・状況`、視線は `視線・構図`、発光・反射・描画フィルターなどは `効果・演出` に残します。顔ひげ・体毛・陰毛も頭髪の `髪` には移していません。キャラクター間の髪型・髪色・目色・肌色のつながりは `作品関係` として、外見そのものから分離しています。`キャラクター`、`作品・シリーズ`、`アーティスト` も別カテゴリのままです。

これで、たとえばキャラクター名や作品名を固定したまま、参照画像から髪だけ、目だけ、表情だけを選ぶ使い方ができます。`wink` はAPI上で投稿数0だったため本体には追加していませんが、将来追加された場合も `表情・感情` に分類されます。

## 追加タグの範囲

Danbooru全タグを無条件に収録したものではありません。APIの全タグには、空タグ、誤入力、複数プロンプトを連結したような名前も含まれるため、今回は次の条件で外見系を追加しました。

- 単体タグとして扱える名前で、空白や `+` 連結を含まない
- 既存CSVにない正規の一般タグ
- 原則として投稿数20以上。リポジトリの最終更新日以降に作成されたタグは投稿数10以上
- 髪・目・肌に関係し、翻訳と分類を確認できたもの

追加台帳の初期分類は髪101・目73・肌22、合計196タグです。全件目視監査後の本体末尾196件の内訳は、髪97・目64・肌20、アクセサリー1・作品関係5・状態・状況1・効果・演出7・顔・メイク1です。台帳には確認時点の投稿数と作成日も残しています。追加対象を広げる場合は、未翻訳・低投稿数タグをいきなり本体へ入れず、まず台帳でレビューしてください。

## 全件目視監査

元の19,329行と追加196行を合わせた19,525行について、英語canonicalタグを日本語訳だけで逆引きせず、タグ名・訳・カテゴリを範囲ごとに目視確認しました。明確なカテゴリ違い、誤訳、装飾・動作・状態・効果と外見の混同を321件修正し、`manual_audit_corrections.csv` に記録しています。台帳の各行は修正前の値を照合してから適用されるため、別の更新で同じindexが変わっていた場合はエラーになります。すでに修正済みのCSVへ再適用した場合は新しい値を確認してスキップします。

## 再生成

リポジトリのルートで次を実行すると、既存行を同じルールで再分類し、台帳の追加行を末尾へ連番付きで追加できます。

```bash
python scripts/refine_index.py \
  --input index.csv \
  --additions data/appearance_tag_additions.csv \
  --corrections data/manual_audit_corrections.csv \
  --output index.csv
```

DanbooruのタグAPIは更新されるため、台帳の投稿数や作成日は固定値です。APIから候補を再取得した場合も、結合プロンプトや動作・アクセサリーを除外し、日本語訳を確認してから台帳へ追加してください。
