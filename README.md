# danbooru-tag-categories-ja

Danbooruタグの日本語名とカテゴリ分類をまとめたCSVデータです。

## 目的

英語のDanbooruタグを、日本語UI・検索・タグ補完・画像管理・プロンプト補助などで扱いやすくするための辞書です。

## ファイル

- `index.csv`: タグ辞書本体

## 列

- `index`: 通し番号
- `tag`: Danbooruタグ
- `db_category_filled`: 英語カテゴリ
- `tag_jp`: 日本語名
- `category_jp`: 日本語カテゴリ

## 注意

このデータには、Danbooruタグ由来の一部NSFWな単語が含まれます。
